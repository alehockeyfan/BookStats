How it works

🇬🇧 Quick guide

  1. Open goodreads.com, go to My Books, then Import/Export.
  2. Download the CSV generated by Export Library.
  3. Load the file with the button above.
  4. All parsing happens in your browser.

🇮🇹 Guida rapida

  1. Apri goodreads.com, vai su My Books, poi Import/Export.
  2. Scarica il CSV generato da Export Library.
  3. Carica il file con il pulsante qui sopra.
  4. Tutta l'elaborazione avviene nel browser.
